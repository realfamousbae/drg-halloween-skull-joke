Летающий хэллоуинский череп больше не ухает зловеще — теперь он играет свой собственный трек.
Только звук, геймплей не меняется. Работает в мультиплеере: слышите только вы.

Audio only, no gameplay changes. Client-side: only you hear it, nobody else needs the mod.
