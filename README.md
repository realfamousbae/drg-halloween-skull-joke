# Halloween Skull Joke

**Русский** · [English](README.en.md)

Мод для **Deep Rock Galactic**: летающий хэллоуинский череп играет твой трек вместо своего idle-звука.

- **Только звук.** В паке лежат одни SoundWave-ассеты и один патченый Sound Cue черепа, геймплей и блюпринты не тронуты.
- **На клиенте.** Музыку слышит только тот, у кого стоит мод. Остальным игрокам в лобби мод не нужен.
- **Звук идёт из самого черепа** (3D), затихает с расстоянием и играет без замедления и ускорения от скорости полёта.

## Как это устроено

Звук черепа играет `HalloweenSkullIdle_Cue`: он смешивает две волны, `HalloweenSkullIdleA_1` и `HalloweenSkullIdleB_1`, и меняет pitch по скорости черепа. Мод подменяет эти ассеты **с теми же путями и именами**, поэтому ни блюпринты, ни мод-лоадер не нужны. Unreal Engine тоже не нужен: звук в SoundWave лежит готовым OGG Vorbis внутри `.uexp`.

| Что меняется | Как |
|---|---|
| `HalloweenSkullIdleA_1` | вместо оригинала твой трек, моно 48 кГц |
| `HalloweenSkullIdleB_1` | 1 с тишины: две копии с разным pitch дают «флэнжер» |
| `HalloweenSkullIdle_Cue` | патч на месте, размеры не меняются: pitch от скорости отключён, без рандомного детюна, громкость трека ×4 (потолок UE), огненный слой под звуком черепа заглушён |

Что выяснилось по ходу работы:

- **Только моно позиционируется в 3D.** Поэтому трек кодируется в моно, чтобы звук шёл от черепа; `--stereo` оставляет стерео.
- **Трек обрезается до 20 с** (`--max-seconds`): в игре волна зациклена.
- **Ваниль тихая** (−20,1 и −17,4 LUFS). Трек выравнивается до −10 LUFS (`--lufs`) с лимитером, потолок true peak −4 dB: Vorbis при декодировании даёт выброс до 3 дБ.
- Огненный слой в том же cue принадлежит боссу-дредноуту, его волны используют другие враги, поэтому они не заменяются, а глушится только слой внутри cue черепа.

Пути и устройство cue: [mod/ASSET_PATHS.md](mod/ASSET_PATHS.md).

## Структура

```
audio/
  placeholder.wav         заглушка (3 с, 44,1 кГц, 16 бит, моно), пока нет трека
  source/                 сюда кладётся исходный трек, в git не хранится
mod/
  ASSET_PATHS.md          пути звуков черепа и устройство cue
  assets.txt              тот же список для pack.ps1
modio/
  description.md          тексты и настройки страницы мода на mod.io
  logo.png                обложка мода на mod.io
CHANGELOG.md              история версий
scripts/
  build_mod.py            трек → build/SkullJoke_P.pak (без UE, через repak + ffmpeg)
  convert_track.sh / .ps1 любой формат → WAV для UE 4.27 (громкость, обрезка)
  pack.ps1                альтернатива: cooked-ассеты из UE → .pak
  install_local.ps1       копирует .pak в FSD/Mods для локальной проверки
```

## Сборка

Нужны Windows, [repak](https://github.com/trumank/repak/releases), Python 3, ffmpeg с `libvorbis` (`winget install Gyan.FFmpeg`) и установленный DRG: оригиналы ассетов берутся из `FSD-WindowsNoEditor.pak`.

Положи трек (mp3, ogg, flac, wav, m4a) в `audio/source/`: берётся первый по алфавиту. Если папка пуста, используется `audio/placeholder.wav`.

```
python scripts\build_mod.py --repak <repak.exe>
```

Результат: `build\SkullJoke_P.pak`. Для mod.io его нужно упаковать в zip.

Параметры:

- `--max-seconds 20` — длина трека, дальше обрезается.
- `--lufs -10` — целевая громкость.
- `--volume 4` — громкость трека в cue.
- `--fade 1` — затухание в конце в секундах, `0` отключает.
- `--stereo` — оставить стерео, но тогда звук не привязан к черепу.

Для локального теста:

```
.\scripts\install_local.ps1 -GameDir '<DRG>'
```

В игре: меню **Modding** → включить локальный мод → перезапуск. Дальше миссия во время хэллоуинского ивента. Свой `.pak` можно открыть в FModel и сравнить путь ассета с оригиналом: если путь не совпадает, замена молча не сработает.

## После патча DRG

```
repak list "<DRG>\FSD\Content\Paks\FSD-WindowsNoEditor.pak"
```

Ищи `Season_Halloween/HalloweenSkull`. Если пути ассетов не изменились, пересобирать не нужно. `build_mod.py` сам проверяет структуру SoundWave и остановится с ошибкой, если она поменялась. Тогда пересобери и залей новую версию файла в тот же мод на mod.io.
